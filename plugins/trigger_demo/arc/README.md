# Trigger Demo — ARC Integration Capsule

This directory (`arc/`) is the **ARC framework integration contract** for the
`trigger_demo` plugin.  It is the only directory the ARC framework needs to know
about.  Algorithm sources live in the sibling `algo/` directory.

---

## Layout

```
arc/                            ← ARC integration capsule root (plugin_root)
├── modules.yml                 ← module registry: 7 modules (4 HLS + 3 RTL)
├── designs/
│   └── design.yml             ← design topology: instances, connections, topology_groups
├── interfaces/
│   └── <module>.interface.yaml ← per-module interface contracts (7 files)
└── verify/
    ├── design.verification.yml ← verification contract (9 flows)
    ├── schemas/data/           ← golden XML dataset
    ├── include/                ← DUT adapter headers
    ├── src/                    ← shared testbench sources
    ├── tests/                  ← per-module testbench cpp
    ├── tools/
    │   ├── bootstrap.py        ← plugin identity / arc verify registration
    │   └── gen_stimulus.py     ← xsim stimulus generator
    └── <flow>/                 ← generated by arc verify generate
```

---

## Path conventions

All relative paths in files inside `arc/` are **relative to their own file's
directory**:

| File | Field | Anchor | Example |
|------|-------|--------|---------|
| `arc/modules.yml` | `src:` / `includes:` / `verify.tb_src:` | `arc/` | `../algo/hit_decoder/hit_decoder.cpp` |
| `arc/modules.yml` | `interface_contract:` | `arc/` | `interfaces/hit_decoder_ip.interface.yaml` |
| `arc/modules.yml` | `verify.tb_args:` | `arc/` | `verify/schemas/data/trigger_demo_golden.xml` |
| `arc/designs/design.yml` | `registry:` | `arc/designs/` | `../modules.yml` |
| `arc/verify/design.verification.yml` | `datasets.xml:` | `arc/verify/` | `schemas/data/trigger_demo_golden.xml` |

**Key point:** `algo/` is a sibling of `arc/`, one level up from the capsule root.
All source and include paths use `../algo/...`.  Verify infrastructure and dataset
files live _inside_ `arc/verify/`, so they need no `../` prefix.

## Quick commands

Run from the arc-framework repo root:

```bash
# Validate registry
arc topgen validate-registry plugins/trigger_demo/arc/modules.yml

# Generate topology
arc topgen gen-top plugins/trigger_demo/arc/designs/design.yml \
  --consumer-root . \
  --contracts-from plugins/trigger_demo/arc/modules.yml \
  --hls-build-root build_hls_trigger_demo \
  --mode verilog --strict \
  --output gen-top/design_trigger_demo_pipeline/algo_top.v

# Generate verify flow files
arc verify generate plugins/trigger_demo/arc/verify/design.verification.yml

# Full pipeline (shortcut)
./run_trigger_demo.sh
```

See `plugins/trigger_demo/README.md` for the complete step-by-step workflow.
